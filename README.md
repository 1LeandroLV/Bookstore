# Bokhandel - Fullstack CRUD Application

## Tech Stack
- React
- ASP.NET Core Web API
- SQL Server
- Entity Framework Core
- xUnit
- NSubstitute

## Funktioner
- Skapa böcker
- Visa böcker
- Uppdatera böcker
- Ta bort böcker
- Relation mellan Books och Authors

## Starta projektet

### Backend
```bash
dotnet run
```

### Frontend
```bash
npm install
npm run dev
```

## Tester
Projektet innehåller enhetstester med:
- xUnit
- NSubstitute
